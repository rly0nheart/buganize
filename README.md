<p align="center">
  Starting from version 3.0.0, <strong>Buganize</strong> has been moved to <strong><a href="https://github.com/rly0nheart/bugpipe">Bugpipe</a></strong>. Functionality remains mostly the same as before with just a few differences. The <code>buganize</code> python package has also been deleted as well, so instead use <code>pip install bugpipe</code>. Again functionality remains mostly the same, and migrating your scripts should be straight forward. 
<br>
<br>
Please read more on <a href="https://bugpipe.readthedocs.io">Read the Docs</a> or check out <a href="https://github.com/rly0nheart/bugpipe/blob/master/CHANGELOG.md">CHANGELOG.md</a> to see what changed.
</p>
