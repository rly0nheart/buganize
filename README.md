<p align="center">
  Buganize has been moved to <a href="https://github.com/rly0nheart/bugpipe">Bugpipe</a>. Functionality remains mostly the same as before with just a few differences. The <code>buganize</code> python package has also been deleted as well, so instead use <code>pip install bugpipe</code>. Again functionality remains mostly the same, and migrating your scripts should be straight forward.

<br>
Please read more on <a href="https://bugpipe.readthedocs.io">Read the Docs</a> or check out <a href="https://github.com/rly0nheart/bugpipe/blob/master/CHANGELOG.md">CHANGELOG.md</a> to see what changed and what got added.
